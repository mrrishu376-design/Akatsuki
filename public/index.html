💡 Why did you see a 404 on Vercel earlier?

This project is a Native Android Application (Kotlin + Jetpack Compose) built with Gradle. Vercel is an engine specifically designed for web apps (Next.js/React/HTML). When Vercel pulled the Android codebase from GitHub without a web entry point, it returned a 404 NOT_FOUND because there were no HTML/JS files to render.

This portal now serves as your official Vercel Web Console & Download Gateway. It documents the platform's forensics architecture, allows auditors to download compiled APK builds, and interfaces with your Supabase database & storage buckets.

Forensic Analysis Capabilities

Key automated capabilities executed during every static APK evaluation:

01
Manifest & Permissions Audit
Extracts and scores dangerous Android permissions (SMS interception, background location, telephony harvesting) against the Android least-privilege baseline with granular impact scoring.
02
Heuristic Malicious Pattern Engine
Scans Dalvik executable (DEX) bytecode for Dynamic Code Loading (DexClassLoader, InMemoryDexClassLoader), commercial packers (Qihoo 360, Bangcle, Legu), and hidden reflection calls.
03
Exported IPC Component Scanner
Identifies unauthenticated Activities, Services, Broadcast Receivers, and Content Providers exposed to third-party apps without permission protection, mapped to CWE-926.
04
Supabase Cloud Evidence Storage
Streams cryptographic evidence dossiers (JSON artifacts, SHA-256 hashes, vulnerability findings) and formal PDF reports directly into Supabase Storage buckets for multi-analyst forensics.
05
Room Local Forensic Database
Persistent offline-first relational storage powered by SQLite & Room (AppDatabase) storing scan history, findings, compliance rules, and user profiles without data loss.
06
PDF Forensic Dossier Generation
Compiles structured, court-admissible forensic PDF reports complete with executive summaries, risk scores (0–100), analyst sign-offs, and remediation instructions.
